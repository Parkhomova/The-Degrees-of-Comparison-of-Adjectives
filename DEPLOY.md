# Как получить ссылку, которую можно отправить ученикам

## Почему ссылка из чата не открывается у учеников

Адрес вида `https://3000-xxxx.e2b.app` — это **служебный туннель песочницы**, а не сайт.
Он защищён токеном, который подставляется только в окне предпросмотра этого чата.
Любой другой человек (ученик, родитель, телефон) получает:

```
403 {"message":"Sandbox is secured with traffic access token.
     Token header 'e2b-traffic-access-token' is missing"}
```

Плюс песочница останавливается при простое — адрес меняется каждый раз.
**Вывод: в группу такую ссылку отправлять нельзя.** Нужен обычный хостинг — ниже три способа.

Приложение к этому полностью готово: таблицы в базе создаются сами при первом запуске
(`src/db/bootstrap.ts`), список из 13 учеников тоже подсевается сам. Команды миграций не нужны —
достаточно одной переменной `DATABASE_URL`.

## Способ A.Render — бесплатно, публичная ссылка, ~10 минут

1. Залейте папку проекта в репозиторий на **github.com** (можно приватный).
2. На **render.com** → `New +` → `Blueprint` → подключите репозиторий.
   Файл `render.yaml` уже лежит в проекте: Render сам создаст сайт и базу PostgreSQL.
3. Дождитесь окончания сборки (2–4 минуты) и нажмите `Deploy`.
4. Готово: ссылка вида `https://comparative-arena.onrender.com` — её и отправляйте в группу.

> Если Blueprint не предлагается: `New +` → `Web Service` → выбрать репозиторий →
> `New +` → `PostgreSQL` → в настройках сайта добавить переменную `DATABASE_URL`
> со значением *Internal Database URL* из базы. Build: `npm ci && npm run build`, Start: `npm run start`.

## Способ B. Railway — бесплатно/пробный баланс, ~5 минут

1. **railway.app** → `New Project` → `Deploy from GitHub repo` (или `GitHub Repo` → указать свой).
2. `New` → `Database` → `PostgreSQL`. Railway сам создаст переменную `DATABASE_URL`.
3. В настройках сервиса включить `Generate Domain` → появится публичный адрес.
4. Отправить ученикам этот адрес. Конфиг `railway.json` уже в проекте.

## Способ C. Vercel + Neon — бесплатно, самый «вечный» адрес

1. **neon.tech** → создать проект → скопировать строку подключения (Pooled connection string).
2. **vercel.com** → `Add New… → Project` → импортировать репозиторий.
3. В поле *Environment Variables* добавить `DATABASE_URL` = строка из Neon → `Deploy`.
4. Ссылка `https://ваш-проект.vercel.app` — постоянная, работает у всех.

## Способ D. Без интернета: урок в классе со своего компьютера

Если занятие проходит в одном кабинете/на одном Wi-Fi, хостинг не нужен вовсе:

```bash
# нужен установленный Docker
docker compose up -d --build
```

- У вас: `http://localhost:3000`
- У учеников: `http://ВАШ_IP:3000` (IP смотрите в настройках сети, например `192.168.1.25`)
- База и все результаты хранятся внутри контейнера и не пропадут после перезапуска.

Чтобы IP не менялся, закрепите его за компьютером в роутере.

## Что писать в группу (шаблон сообщения)

> **Английский язык — самостоятельный урок**
> Тема: степени сравнения прилагательных (вторая степень / comparative degree).
> Ссылка: `ВСТАВИТЬ_ССЫЛКУ`
>
> Как проходить:
> 1. Открой ссылку и **выбери себя** из списка класса (иначе результат не попадёт в рейтинг).
> 2. Пройди правило: 6 станций, кликай по словам, отвечай в мини-проверках.
> 3. Пройди 4 раунда на время: тест 15 с → конструктор 45 с → «найди ошибку» 25 с → блиц 45 с.
> 4. В конце зайди на «Арену вызовов» и кинь вызов однокласснику.
> 5. Рейтинг класса (открыт всем): `ВСТАВИТЬ_ССЫЛКУ/leaderboard`
>
> Звук можно выключить кнопкой в правом верхнем углу. Занимает 15–20 минут.
> Проходить можно с телефона или компьютера, попыток неограниченно — в рейтинг идёт лучший результат.

## Полезно знать

- **Состав класса** меняется в одном файле: `src/lib/students.ts` (массивы `CLASS_LIST`, `ACCENTS`).
  После правки достаточно пересобрать/перезапустить сервис — новые имена добавятся сами.
- **Прямые ссылки** для конкретного ученика: `…/lesson?sid=N`, где N — номер из таблицы `students`
  (порядок совпадает со списком класса: 1 — Мерчук Саша … 13 — Шульпина Милана).
- **Сбросить результаты** класса: выполнить в базе `truncate attempts, duels restart identity cascade;`
- **Если база временно недоступна**, урок не ломается: ученик проходит его целиком, результат
  сохраняется в его браузере и автоматически уходит в рейтинг, когда сервер ответит.
