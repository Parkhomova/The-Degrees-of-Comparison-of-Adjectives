# COMPARATIVE DEGREE ARENA

Интерактивный урок английского языка для самостоятельной работы:
**вторая степень сравнения прилагательных** (comparative degree).

Правило (6 интерактивных станций + «машина прилагательных»), 4 раунда на время,
дуэли между учениками и общая таблица лидеров класса.

Стек: Next.js (App Router) · React 19 · Tailwind CSS 4 · Drizzle ORM · PostgreSQL.

---

## Что видит ученик

1. **Выбор себя из списка класса** — работа выполняется от имени ученика.
   Состав класса правится в `src/lib/students.ts` (массив `CLASS_LIST`); база синхронизируется сама.
2. **Правило**: три ступени → короткие слова `+er` → орфография (`-e`→`-r`, удвоение CVC, `-y`→`-ier`)
   → длинные `more +` → исключения (`good/bad/far/little`) → конструкция с `than`.
   На каждой станции — кликабельные превращения слов и мини-проверки (+40 XP).
   «Машина прилагательных» принимает любое слово и показывает, какое правило сработало.
3. **Раунды на время** (вопросы генерируются заново для каждой попытки):
   - Раунд 1 «Быстрый выбор» — 8 вопросов × 15 с, бонус за скорость;
   - Раунд 2 «Конструктор» — 5 предложений × 45 с, сборка из плиток (есть лишние);
   - Раунд 3 «Найди ошибку» — 6 предложений × 25 с, два шага: найти битое слово и заменить его;
   - Раунд 4 «Блиц» — 45 с без пауз, комбо ×1…×5, ошибка отнимает 2 секунды.
4. **Результат**: звание, XP, точность, время, место в классе, разбор по раундам.
5. **Арена вызовов**: выбрать одноклассника и сыграть блиц на 45 с. Соперник получает вызов
   и отвечает **тем же набором вопросов** (общий seed) — идёт живая гонка полос.
6. **Таблица лидеров** (`/leaderboard`) — открыта для всех, обновляется каждые 12 секунд:
   подиум, полная таблица класса, сортировки (XP / точность / дуэли / список), лента вызовов.

## Быстрый запуск локально

Нужны Node.js 20+ и PostgreSQL.

```bash
npm install

# 1. база
export DATABASE_URL="postgresql://postgres:postgres@127.0.0.1:5432/app_db"

# 2. схема (таблицы students / attempts / duels)
npx drizzle-kit push

# 3. запуск
npm run dev        # разработка
# или
npm run build && npm run start
```

Список класса создаётся автоматически при первом обращении к приложению —
отдельный сид-скрипт не нужен.

### Изменить состав класса

Отредактируйте массивы `CLASS_LIST` и `ACCENTS` в `src/lib/students.ts`.
Новые имена добавятся при следующем запросе (существующие не затрагиваются).

## Запуск в Docker одной командой

```bash
docker compose up -d --build
# урок:      http://localhost:3000
# рейтинг:   http://localhost:3000/leaderboard
```

`docker compose` поднимает PostgreSQL и приложение; схема применяется автоматически
при старте контейнера (entrypoint вызывает `drizzle-kit push`).

## Постоянная ссылка для класса (деплой)

Превью-песочницы дают временный адрес, который меняется при перезапуске.
Чтобы ссылка была вечной, задеплойте проект на свой хостинг:

| Шаг | Что сделать |
|---|---|
| 1 | Создать PostgreSQL (Neon, Supabase, Railway, свой сервер) |
| 2 | Задать переменную `DATABASE_URL` в настройках хостинга |
| 3 | Задеплоить репозиторий: build `npm run build`, start `npm run start` |
| 4 | Один раз выполнить `npx drizzle-kit push` с этим `DATABASE_URL` |
| 5 | Раздать ученикам ссылку вида `https://ваш-домен/` и `https://ваш-домен/leaderboard` |

Vercel: импортировать репозиторий → добавить `DATABASE_URL` → Deploy.
После деплоя один раз запустить `DATABASE_URL=... npx drizzle-kit push` локально.

### Прямые ссылки для учеников

`/lesson?sid=N`, где N — id ученика из таблицы `students`
(порядок = порядок в `CLASS_LIST`, первый ученик обычно `sid=1`).

---

## Устойчивость к сбоям

- Если база недоступна, страницы **не падают**: список класса детерминирован,
  правило и все раунды работают полностью, показывается баннер «Автономный режим».
- Результат урока в этом случае кладётся в очередь в `localStorage` и
  автоматически отправляется на сервер, когда тот снова отвечает
  (проверка каждые 30 секунд, компонент `PendingSync`).

## Структура

```
src/
  app/
    page.tsx                  # выбор ученика из списка класса
    lesson/page.tsx           # оболочка урока (sid = id ученика)
    leaderboard/page.tsx      # общий рейтинг
    api/attempts              # POST результата урока
    api/duels                 # POST вызова / PATCH ответа на вызов
    api/leaderboard           # данные рейтинга + лента дуэлей
    api/health                # healthcheck
  components/
    LessonShell.tsx           # брифинг → правило → 4 раунда → результат → арена
    Theory.tsx                # 6 станций правила + «машина прилагательных»
    Practice.tsx              # раунды: выбор, конструктор, ошибки, блиц
    DuelArena.tsx             # вызов однокласснику, гонка, журнал дуэлей
    Board.tsx                 # таблица лидеров, подиум, лента вызовов
    Home.tsx                  # главная: список класса, лидеры, маршрут урока
    PendingSync.tsx           # дозвонка локальной очереди на сервер
    ui.tsx                    # аватары, таймер, конфетти, звук-тумблер, баннеры
  lib/
    grammar.ts                # движок образования второй степени + типичные ошибки
    questions.ts              # словарь (76 прилагательных), 20 предложений, генераторы
    board.ts / board-types.ts # выборки рейтинга, устойчивые к отказу БД
    students.ts               # список класса, цвета, посев
    sound.ts                  # синтезированные звуки на Web Audio API
    localStore.ts             # очередь результатов в localStorage
  db/
    schema.ts                 # students, attempts, duels
```
